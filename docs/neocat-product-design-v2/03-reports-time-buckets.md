# 03｜报表、时间桶与诊断

## 1. 公共报表入口

登录用户选择服务后进入 Transaction。所有报表共用：

- 服务选择；
- 当前报表类型；
- 时间范围；
- 实例筛选；
- 当前平台时区；
- 数据质量标记。

服务/实例列表按当前报表类型和当前时间范围有数据才展示。

## 2. 时间范围与桶

### 2.1 固定周期

| 范围 | 时间边界 | 每点区间 |
|---|---|---:|
| 某小时 | 平台时区整点至下一整点 | 1分钟 |
| 某自然日 | 00:00至次日00:00 | 10分钟 |
| 某自然周 | 周一00:00至下周一00:00 | 1小时 |
| 某自然月 | 月初00:00至下月初00:00 | 1自然日 |

### 2.2 快捷范围

进入报表页的**默认窗口是当前自然小时**（平台时区整点对齐，如 `19:00 – 20:00`），
不是从当前时刻往回滚的「最近 1 小时」。滚动窗口的区间带零头（`18:59 – 19:59`），
既不好读，也无法与整点的历史窗口直接比较；当前小时最后一个桶是实时桶。

| 快捷项 | 默认粒度 |
|---|---:|
| 当前小时 | 1分钟 |
| 最近1小时 | 1分钟 |
| 最近3小时 | 5分钟 |
| 最近6小时 | 10分钟 |
| 最近12小时 | 20分钟 |
| 最近24小时 | 1小时 |
| 今天 | 10分钟 |
| 本周 | 1小时 |

滚动范围的桶边界按平台时区固定边界对齐。首尾部分桶保留，只计算落入实际查询范围的数据，并标记“部分覆盖”。

### 2.3 点的定义

所有点均表示左闭右开区间：

```text
[bucketStart, bucketEnd)
```

例如 `10:20` 点表示 `10:20:00`（含）至 `10:30:00`（不含）的数据。横轴标起点，Tooltip 显示完整区间。

当前正在写入的点标记为实时/未完成，每分钟原位更新，不重复追加。

## 3. 桶内聚合

| 统计项 | 桶内算法 |
|---|---|
| Hits/总量 | 所有事件次数求和 |
| Failures | 失败事件次数求和 |
| QPS | 桶内总次数 ÷ 桶实际覆盖秒数 |
| Avg Duration | 桶内总耗时 ÷ 桶内总次数 |
| Failure Rate | 桶内失败次数 ÷ 桶内总次数 |
| Min/Max | 取真实最小/最大值 |
| tp50–tp9999 | 合并原始耗时分布后重新计算 |
| 大盘公式 | 先将输入序列对齐到同一桶，再计算 |

不能平均各子桶的平均值、分位或机器 QPS；应先合并分子/分布再计算。

## 4. QPS 与趋势显示

表格 QPS采用 CAT 口径：

```text
范围总次数 / 范围实际覆盖秒数
```

当前小时使用整点至当前时刻的实际秒数；完整历史小时使用3600秒；自然日/周/月和快捷范围使用实际覆盖秒数。

趋势默认显示桶内 Hits 总次数：

- 10分钟桶收到120次，点显示120；
- 需要速率时切换为 QPS，点显示120/该桶实际秒数；
- 不把 `count/min` 或 `count/day` 直接标成 QPS。

## 5. 空数据与部分数据

- 桶内确认无调用：Hits、Failures、QPS 显示0；
- 无调用时 Avg、Failure Rate、分位显示无值；
- 因丢弃、分析失败或序列未出现：显示缺口，不显示0；
- 部分覆盖桶按实际覆盖秒数计算；
- 当前桶照常展示并标记实时；
- 缺数会在图表、Tooltip 和预告警试算中保持未知语义。

## 6. 环比

Transaction、Event、Problem、Metric 支持：

- 1天前同时段；
- 7天前同时段；
- 30天前同时段。

对比按平台时区整日偏移，月环比不是上一个自然月。按桶序号对齐：例如当前 `10:20–10:30` 对齐偏移后同一时段的桶。Heartbeat 一期不做环比。

## 7. Transaction

### 7.1 Type 层

进入服务 Transaction 后展示 Type 汇总。Type 只承担分类汇总和进入 Name 列表，不直接进入趋势详情。

展示：

- Type；
- 总量、失败量、失败率；
- 最小耗时、最大耗时、平均耗时；
- tp50、tp90、tp95、tp99、tp999、tp9999；
- CAT 口径 QPS；
- 最近30条取样。

### 7.2 Name 层

点击 Type 后进入 Name 列表，字段与 Type 类似，但统计范围限定在该 Type。

点击 Name 后进入趋势详情：

- 默认全部机器聚合；
- 默认显示 Hits（每个桶的打点总次数）；
- 统计项一次单选；
- 可选失败量、失败率、QPS、平均耗时、各分位、最小/最大等适用项；
- 可切换固定周期或快捷时间范围；
- 可切换机器维度。

### 7.3 机器维度

机器视图：

- 默认按当前统计项贡献值从高到低显示 Top N；
- Top N 之外的机器合并为 `other`，用于数量类/速率类与总量对账；
- 全部机器在可搜索、可排序、可分页的明细表中展示；
- 用户可以勾选机器进行对比；
- 手动选机器后展示选中机器，不再自动加入 `other`。

## 8. Event

Event 遵循同样的 `Type → Name → 趋势` 交互：

- 默认全部机器聚合；
- 默认 Hits 总次数趋势；
- 可切换失败量、失败率、Event QPS；
- 可按机器对比；
- 每行最近30条取样。

Event 不提供耗时、最小/最大/平均耗时、耗时分布和百分位。

## 9. Problem

Problem 分类：

1. 异常；
2. 慢请求；
3. 慢 SQL；
4. 慢调用；
5. 慢缓存。

来源：

- Transaction/Event 非成功状态 → 异常；
- URL、SQL、RPC/Call、Cache/缓存 Transaction 超过对应平台阈值 → 慢类。

默认阈值：URL 1000ms、SQL 100ms、调用1000ms、缓存50ms。平台阈值只影响后续处理，不重算历史。

列表行为：

- 异常分类内按异常名聚合；完整异常消息只保留在取样/Trace；
- 慢类内按 Transaction Name 聚合；
- 同一次调用可以同时属于异常和慢类；
- 慢类支持耗时分位和环比；
- 异常只支持次数和环比，不支持分位。

Problem 页面自定义阈值只筛选已经归类的慢记录，不重新定义历史类别；在报表留存期内要求精确筛选。

## 10. Heartbeat

一期只支持 JVM，图表标题用点分指标名展示：

- 堆内存：`jvm.memory.heap.used`、`jvm.memory.heap.max`；
- 内存分区：年轻代、老年代、元空间各含 `.used`、`.committed`、`.max`；
- GC：`jvm.gc.count`、`jvm.gc.time`，以及 `jvm.gc.{young,old,full}.{count,time}`；
- 线程：`jvm.threads.live`。

单位与指标名分开标注：内存为 `bytes`，GC 耗时为 `ms`，次数为 `count`。

点分指标名是展示名，与接口参数（`heap-used` 等）分开：改展示名不动接口契约。
业内没有唯一命名规范（Micrometer 等用 `jvm.memory.used` 加内存池标签），
这里沿用常见 JVM 术语按点分形式展开，不代表某个框架的原生指标名。

内存分区的 `used`、`committed`、`max` 是三个不同口径，与 JVM `MemoryPoolMXBean` 同名：
`used` 是已占用，`committed` 是 JVM 已申请、保证可用的容量（**不是对象实际占用，也不等于进程 RSS**），
`max` 是最大可用容量。元空间属于非堆内存，不计入堆，默认无上限——
`-XX:MaxMetaspaceSize` 未设置时 `metaspace.max` 未定义，显示为空缺而不是 0。

这些口径说明不写成页面上的整段文字，而是放在每张指标小图标题右侧的 `?` 提示里：
标题顺序为“指标名称 [?] 单位”。悬停或键盘聚焦显示悬浮 tips，触屏可点击开关；
浮层不撑高图表，Esc 或点击别处收起。GC 的收集器区分与累计值语义同理。
口径文字保存在 `front/src/api/heartbeat.ts` 编目里，与指标一一对应，增删指标只改一处。

默认按实例分别展示：

- 图上按当前指标值从高到低取 Top N；
- Top N 之外不合并为 `other`；
- 其余实例出现在可搜索、可分页的实例表，可手动加入对比；
- 不将不同 JVM 的堆、线程等相加；内存分区之间也不相加（元空间是非堆）；
- 非 JVM 服务没有 Heartbeat 页；
- 一期不做 Heartbeat 日/周/月环比。

## 11. 调用取样与 Trace 入口

每个 Transaction/Event/Problem 行按事件时间倒序展示最近30条调用取样，多行展示，不把更早的异常调用插入最新顺序。

取样查询受当前服务、时间范围、实例、Type/Name/Problem 筛选约束。点击后进入 Trace；超过7天的原始树显示过期，不允许打开。

## 12. 报表验收

1. Type 点击只进入 Name 列表。
2. Name 默认趋势是每桶 Hits 总次数，不是最大耗时或默认 QPS。
3. Event 有 QPS，没有耗时和分位。
4. 当前小时 QPS不固定除3600。
5. 周趋势为1小时/点，最近12小时为20分钟/点。
6. 缺数据不显示为0，真实无调用才显示0。
7. 每行最多展示最近30条取样，过期 Trace 不可打开。
