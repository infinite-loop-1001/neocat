# 05｜组织大盘与卡片

## 1. 范围与权限

大盘只挂在叶子组织上。每个叶子可以有一块或多块大盘。

可访问人员：

- 直接加入该叶子的成员；
- 加入该叶子任意祖先组织的成员。

管理员和超管没有自动旁路；不具备成员资格时看不到入口，也不能通过 ID 访问。

## 2. 大盘生命周期

```text
不存在
→ 成员创建
→ 可编辑
→ 成员添加/修改/删除卡片
→ 成员删除大盘
→ 叶子组织删除时级联删除
```

一期支持：

- 创建、命名、删除大盘；
- 创建、编辑、删除卡片；
- 调整卡片顺序；
- 选择指标对象、统计项、公式和时间范围；
- 配置阈值线；
- 点击卡片进入标准趋势详情。

个人私有大盘不在一期范围内。

## 3. 卡片目标范围

一张卡片只能绑定：

```text
一个服务 + 一个指标对象
```

例如：

- 一个 Transaction Name；
- 一个 Event Name；
- 一个 Problem Name；
- 一个 Metric 指标名和标签组合；
- 一个 Heartbeat 指标及明确实例视图。

同一大盘可以通过多张卡片覆盖不同服务和指标对象，但一张卡片不能跨服务、跨 Name 组合输入。

## 4. 统计项与公式

同一指标对象可以引用多个统计项，例如：

- `failure / hits`；
- `p99` 与 `avg`；
- `current - baseline`。

一期支持：

- `sum`、`avg`、`min`、`max` 聚合；
- `+`、`-`、`*`、`/` 四则运算；
- 常数参与运算；
- 单一指标对象的多维度先聚合，再按机器等维度下钻。

界面不列单位，但系统内部必须校验单位兼容：

- 加减要求单位兼容；
- 乘除推导结果单位；
- 除数为0时该点不可计算；
- 不符合校验的公式不能保存。

不支持自由脚本、条件表达式、跨服务公式或跨 Name 公式。

## 5. 时间对齐与缺数

卡片计算前先将同一指标的输入统计项对齐到相同时间桶，再执行公式。

- 任意输入在该桶缺数：结果为缺口；
- 不把缺数当0；
- 不沿用上一点；
- Tooltip 显示缺失的输入；
- 除零显示“不可计算”。

卡片支持总纲规定的固定周期和快捷时间范围。

## 6. 机器维度

卡片默认展示全部机器聚合结果。成员可以进入维度下钻：

- 查看各机器结果；
- 选择机器对比；
- 查看 Top N 和分页明细；
- 返回全部机器聚合。

机器下钻只用于诊断，不改变卡片的默认目标。

## 7. 阈值线

阈值线是卡片的可视化配置：

- 可以在图上添加高于/低于的阈值线；
- 默认只用于视觉对照；
- 作用于卡片全部机器聚合结果；
- 机器下钻不自动变成逐机器阈值线；
- 阈值线修改不自动修改已有告警规则的比较阈值。

## 8. 从卡片创建组织告警

成员可以从卡片当前计算结果一键进入组织告警配置：

```text
卡片
→ 复制当前目标和公式
→ 用户补充条件、AND/OR、窗口、接收人和通道
→ 保存为关闭状态
→ 保存前显示预告警
→ 手动启用
```

一键创建后：

- 告警的条件、阈值和接收人独立于阈值线；
- 卡片公式修改后，关联告警目标跟随新公式；
- 公式变化后告警窗口从零开始；
- 修改已启用卡片公式会使关联规则保存为关闭状态，需再次启用；
- 卡片删除后关联规则失效但保留配置。

## 9. 组织告警指标并集

组织告警可选择：

1. 该叶子所有大盘已引用的原始统计项；
2. 该叶子大盘中的卡片计算结果。

如果某原始统计项从一张卡片移除但仍被另一张卡片引用，组织告警继续有效。只有最后一个引用消失时，规则才失效但保留。

## 10. 大盘修改与拓扑约束

- 叶子有大盘或组织告警时不能新增子节点；
- 删除叶子时大盘、卡片和组织告警原子级联删除；
- 成员失去权限后不能继续修改，已打开页面下次请求重新校验；
- 无叶子组织或无相关成员时不显示组织大盘入口；
- 服务监控本身不受组织大盘权限影响。

## 11. 大盘验收

1. 非成员看不到大盘入口和内容。
2. 祖先成员可以看和改全部后代叶子大盘。
3. 一张卡片不允许跨服务/跨 Name 公式。
4. 同一指标多统计项可聚合和四则运算，单位非法不能保存。
5. 缺数和除零产生缺口。
6. 机器下钻不改变默认聚合阈值和告警范围。
7. 公式变更跟随规则但清零窗口，卡片删除使规则失效。
