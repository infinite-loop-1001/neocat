# 01｜身份、会话与组织权限

## 1. 范围

本域负责平台初始化、账号、密码、登录会话、系统角色、组织树、组织成员和叶子组织权限。不负责服务报表数据权限；服务报表对所有已登录用户开放。

## 2. 平台初始化

### 2.1 初始化输入

部署首次启动时必须提供：

- 平台时区；
- 第一个超级管理员用户名；
- 第一个超级管理员初始口令。

平台初始化同时建立：

- 默认慢 URL、慢 SQL、慢调用、慢缓存阈值；
- 空的邮件、钉钉、飞书通道配置；
- 无组织、无大盘、无组织告警的初始状态。

平台时区初始化后一期不可在页面修改。所有自然周期和告警判定使用同一时区。

## 3. 账号生命周期

### 3.1 创建账号

前置条件：当前用户是 `ADMIN` 或 `SUPER_ADMIN`。

流程：

```text
填写用户名和临时密码
→ 校验用户名唯一
→ 校验密码至少8位
→ 创建 USER 账号
→ 标记“首次登录必须改密”
```

管理员只能创建普通用户。只有超级管理员可以授予 `ADMIN`。

用户名一旦创建，一期不支持修改；删除账号不在一期范围内。

### 3.2 授予/取消管理员

只有 `SUPER_ADMIN` 能执行：

- `USER → ADMIN`；
- `ADMIN → USER`。

不能通过普通创建账号接口绕过该规则。超级管理员自身不能被普通管理员修改。

### 3.3 重置密码

管理员可以重置任意普通用户或管理员密码。重置后：

- 新密码必须至少8位；
- 用户下次登录必须修改密码；
- 已有会话是否继续有效：重置后全部失效，用户需用新密码重新登录。

### 3.4 禁用/启用

管理员可以禁用/启用账号；超级管理员可管理管理员账号。

禁用流程：

```text
禁用账号
→ 立即失效该用户全部会话
→ 从服务告警/组织告警收件人中移除
→ 保留组织直接成员关系
→ 账号不可登录、不可作为新收件人
```

启用流程：

```text
启用账号
→ 可重新登录
→ 恢复原组织成员继承资格
→ 不自动恢复任何告警收件关系
```

## 4. 登录与会话

### 4.1 登录

```text
提交用户名/密码
→ 检查账号存在且启用
→ 校验密码
→ 创建当前浏览器会话
→ 标记会话滑动过期时间
→ 查询最近访问服务
```

成功入口：

- 有可用最近访问服务：进入该服务 `Transaction`；
- 没有记录或该服务在当前查询范围内无数据：进入服务列表。

失败时只返回通用凭据错误，不暴露账号是否存在。

### 4.2 会话规则

- 会话滑动有效期为30分钟；每次有效请求刷新过期时间；
- 允许同一账号多处同时登录；
- 登出只注销当前会话；
- 账号禁用、密码重置会使该账号全部会话失效；
- 未登录不能访问任何报表、管理或组织资源。

### 4.3 首次改密

首次登录或重置密码后的临时会话只能进入改密流程：

```text
临时密码登录
→ 提交新密码（至少8位）
→ 新旧密码不能相同
→ 更新凭据
→ 清除首次改密标记
→ 进入最近服务 Transaction/服务列表
```

## 5. 组织树模型

- 组织是树；允许多个根节点；
- 节点可有直接成员；用户可以加入多个节点；
- 叶子节点才能拥有大盘；
- 非叶子节点不能拥有大盘；
- 组织节点支持创建、改名、添加成员、移除成员、删除；移动节点一期不做。

### 5.1 创建节点

管理员选择父节点或根节点，系统校验名称在同一父节点下唯一。创建后：

- 无子节点的节点是叶子；
- 有子节点的节点是非叶子；
- 新建叶子没有大盘和告警。

### 5.2 叶子变非叶子

如果叶子已经存在任意大盘或组织告警，新增子节点必须被阻止。管理员需要先删除或完成产品支持的迁移操作；一期没有自动迁移，因此实际流程是清理后再新增子节点。

### 5.3 删除节点

- 非叶子节点存在子节点时禁止删除；
- 删除叶子前展示组织、大盘、卡片和组织告警影响范围；
- 管理员输入组织名进行二次确认；
- 确认后原子删除叶子、大盘、卡片和组织告警；
- 删除完成后所有成员立即失去该叶子权限。

## 6. 成员继承与权限计算

用户对某叶子组织的有效成员资格来自两类路径：

1. 用户直接加入该叶子；
2. 用户加入该叶子的任意祖先节点。

有效叶子集合每次组织成员变更后立即重新计算。

移除一条成员关系时：

- 如果用户还有其他路径到达叶子，权限保留；
- 如果没有任何路径，权限立即撤销；
- 已打开的组织页面下一次请求必须重新校验并拒绝无权限访问；
- 该用户从相关组织告警收件人中移除。

管理员角色不提供组织权限旁路。

## 7. 权限行为

### 7.1 服务报表

所有已登录用户都能查看当前筛选范围内所有服务，并能配置任意服务的服务告警。服务与组织没有绑定关系。

### 7.2 组织大盘/告警

只有叶子直接成员和祖先继承成员可以：

- 看到该叶子大盘入口；
- 查看和修改大盘、卡片、阈值线；
- 创建、编辑、删除、启用或关闭该叶子组织告警。

非成员不能通过列表、链接、ID 或接口访问。

## 8. 一期验收

1. 首次启动可创建指定时区和超管。
2. 管理员能创建8位以上密码的普通账号，首次登录强制改密。
3. 管理员不能授予 ADMIN，超管可以授予和取消。
4. 会话滑动30分钟，允许多会话，退出只注销当前会话。
5. 禁用账号立即踢出全部会话并移除告警收件人，启用后恢复组织成员但不恢复收件人。
6. 祖先成员能访问所有后代叶子，移除后即时失效。
7. 有大盘/组织告警的叶子不能直接新增子节点。
8. 删除叶子必须二次确认并级联删除大盘、卡片和组织告警。
