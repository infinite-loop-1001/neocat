# 趋势图悬浮提示精简

日期：2026-10-03
状态：用户已确认顶部统一时间的新格式，已实施并通过回归。

## 已批准的格式

只改 `ReportChart`（Transaction/Event/Problem 趋势、Metric 详情、大盘卡片图）的悬浮提示，不改数值、缺口语义与请求：

- 顶部统一显示一次当前横轴桶起点，固定格式 `yyyy-mm-dd HH:mm:ss`，继续沿用页面本地时区，不使用 UTC 转换。
- 单曲线：顶部时间，下一行只显示 `59`。
- 环比多曲线：时间下逐行显示 `当前：59`、`日环比：52` 等，不重复时间。即使当前线隐藏，标题也不使用历史线日期。
- 缺口的数据行仍提示 `缺口`，不再附带 `（实时（未完成））` 之类质量说明。
- 不显示统计项名（`HITS`）。此方案取代早先每行显示 `59 (01:04)` 的方案。

系列名与质量说明不再进入提示，因此图下说明从「缺口以断线表示；悬停查看质量标记。」改为「缺口以断线表示。」。`MiniChart`（Heartbeat 与 Metric 总览小图）保持原样。

## 影响与取舍

提示不再说明「实时未完成 / 部分覆盖 / 合入 other」。Metric 详情仍在图下单独说明 `MERGED_OTHER`；Heartbeat 小图仍保留原有质量提示。若后续需要恢复质量说明，应在图下或图例承载，而不是塞回提示框。

## 验证

提示格式回归覆盖：单曲线、缺口、环比四线、当前线隐藏后仍使用当前横轴日期、固定时间补零、空参数与空轴兜底；锁定图下说明不再声称悬停可看质量标记。执行前端全量测试、类型检查、生产构建及动线检查。

本地前端验收，不代表后端现场联调。目录不是 Git 仓库，无法提交或推送。
