# Metric 空数据图表与验收 mock

日期：2026-10-03
状态：用户已批准并实施，离线回归通过；前端视觉验收待用户确认。后端分包和部署文档任务已先行完成。

## 1. 目标与边界

用户要求：Metric 没有数据时仍展示图表，只是不画数据点；提供无数据 mock 供前端验收。

仅调整 Metric 总览与详情。保持默认正常 mock、真实 API 契约、单条 count 曲线、标签 OR/AND、缺失不补零及禁止未来窗口。共享图表新增能力应由 Metric 显式启用，不改变 Heartbeat 等现有调用方的空态。

## 2. 展示方案

推荐保留图表框架，而不是以空文案替换整个图表，也不画 0 值基线。

- **总览**：已知 Metric 每个保留一张小图，含标题、时间轴、纵轴、现有总量图例和详情入口；`points: []` 或全部 null 都没有折线/点。无数据说明在图下简短显示，不覆盖绘图区。
- **详情**：保留标签筛选、时间范围、曲线口径和大图；无数据时显示空坐标轴。`MERGED_OTHER` 的不可恢复说明放图下，不能当作普通零值或接口失败。
- **没有指标目录**：没有可命名的 Metric 时，保留“当前时间范围没有 Metric”，不制造不存在的指标卡片。
- **加载/错误**：保留加载状态和错误重试。小图请求失败仍显示该指标错误，不伪装成空数据；其他正常卡片不受影响。
- **时间轴**：优先使用响应真实桶；空数组时仅用本次已选择时间范围生成轴刻度，不生成业务 Point，不填 0，也不以刻度表示未来已经发生。计算沿用现有时间范围规则，并在一次加载内固定参考时间。

## 3. 隔离的验收入口

使用可切换 URL 场景而不是清空默认 mock：

| URL 场景 | 内容 | 验收目标 |
|---|---|---|
| 不带场景参数 | 现有正常数据 | 默认行为不变 |
| `mockMetric=all-null` | 保留目录/标签，已有桶全部无有效值 | 无数据点但坐标轴/图例存在 |
| `mockMetric=empty-points` | 保留目录/标签，count 返回空数组 | 空数组仍有选定范围时间轴 |
| `mockMetric=partial` | 部分指标无数据，其余正常 | 小图独立渲染及正常下钻 |

场景只在 mock 分支生效，真实 API 请求不附加场景参数且不回退假数据。总览进入详情、返回总览、切换时间和标签筛选保留场景；删除参数恢复正常。未知场景按正常 mock 处理。目录和标签保留是专门用于前端空态验收的替身，不声称真实后端会在目录为空时返回这些指标。

## 4. 实现边界

- `MetricView.vue` 不再用 `!hasValue` 替换详情图表，改为图下说明；仅 Metric 小图显式开启空轴能力。
- `MiniChart.vue` 的空图能力默认关闭，保持 Heartbeat 原空态说明。`ReportChart.vue` 增加可选空轴刻度输入，默认行为不变。
- 空轴时间范围工具与 mock 场景解析各自独立、可单测。视图不导入 mock 数据集，图表组件不读取浏览器 URL。
- mock 数据集/路由读取受控场景；现有 count 算法和标签筛选逻辑不被全局改写。

新增回归覆盖空数组、全 null、MERGED_OTHER、真实 0、局部卡片错误、空目录、场景导航保持及真实模式隔离；共享图表其他调用方保持现状。执行前端测试、flow 和 build，以及契约脚本。

## 6. 实施与验收入口

- 空轴仅提供时间刻度；空图纵轴使用 0–1 占位刻度以避免 ECharts 在全 null 时隐藏纵轴，不生成任何业务数据或 0 值曲线。
- `client.ts` 只在 mock 分支消费独立 `mockMetric` 选项；真实请求忽略此选项。不是页面直接依赖 mock 数据集，也不从浏览器全局读取场景。
- 小图通过 `showEmptyChart` 显式开启，Heartbeat 未传此选项，其原有空态回归保持通过。详情用响应桶优先、空数组时间刻度兜底。
- 本地默认开发服务：`http://localhost:5173`。验收链接：
  - `/svc/order/metric?mockMetric=all-null`：全部指标已有桶、全 null。
  - `/svc/order/metric?mockMetric=empty-points`：全部指标返回空数组。
  - `/svc/order/metric?mockMetric=partial`：order.amount/payment.latency 空，queue.depth 正常。
  - `/svc/order/metric/order.amount?mockMetric=empty-points`：详情空数组。
  - `/svc/order/metric`：恢复正常默认 mock。
- 若登录失效，使用本地 mock 账号登录后重新打开验收链接；登录页不保留目的地址，这是既有行为。以上替身场景保留目录和标签仅供前端验收，不代表真实后端目录发现结果。
