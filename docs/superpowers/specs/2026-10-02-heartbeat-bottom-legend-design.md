# Heartbeat 小图底部机器图例

用户已确认：所有 Heartbeat 指标小图中的机器 IP 图例移到图下，按机器逐行展示。

- 仅修改共享 `MiniChart.vue`，内存、GC、线程的小图统一生效。
- 标题、绘图区、横轴、机器图例依次排列；图例采用 HTML 列表，每台机器独占一行。
- 机器色标与曲线一致，隐藏曲线不会改变其他机器的颜色。
- 点击图例行隐藏／恢复本图中对应曲线；使用原生按钮支持键盘操作与按下状态。
- 单机器也展示图例；较长列表限制高度并独立滚动，不压缩绘图区。
- 全空指标保留原有无数据说明及机器列表，不填零；隐藏所有曲线不被当作缺数。
- 实例被移出筛选后清除它的本图隐藏状态，重新加入时显示。
- 顶部实例筛选器、其他报表的 `ReportChart.vue`、接口和 mock 数据保持不变。
