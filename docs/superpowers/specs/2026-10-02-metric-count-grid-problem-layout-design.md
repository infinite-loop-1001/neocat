# Metric count 总览、标签筛选详情与 Problem 全宽布局

## 已确认需求

- Metric 入口按指标名称展示 Heartbeat 风格的并排趋势小图，不再展示标签排名表。
- 每张小图默认只有一条线：该 Metric 每个时间桶的 count 总量，即上报次数，不是数值总和或标签组合数量。
- 点击进入该 Metric 的大折线详情页，默认仍是同一条 count 总量曲线，不预选标签。
- 只有用户选择标签条件时，才展示符合条件的数据聚合得到的一条 count 曲线；清空条件恢复全量。
- Problem 删除顶部三段说明，放开宽度限制，表格铺满右侧内容区，并增加行间距。
- 本轮只改前端、mock、相关文档和单测；不修改后端、采集协议或 Java 客户端。浏览器功能测试由用户负责。

## Metric 页面与交互

### 总览

保留服务导航和共享时间控件。每个指标名对应一张小图，单位为 count，标题使用真实指标名称。
每张图只有该指标的全量 count 曲线，不默认拆标签。标题及明确的“查看详情”链接进入独立详情路由
`/svc/:service/metric/:metric`；不把整张图包成按钮，避免图例与下钻点击冲突。
图表网格适应右侧内容区宽度，小屏降为单列。

### 详情

标题显示当前指标名称，提供返回 Metric 总览入口、共享时间控件和大折线图。
首次进入不带标签条件，图例为“总量”。标签键与候选值来自当前指标的数据，不使用跨指标候选集合。
筛选采用标签键下的值选择：同一键多值为 OR，不同键为 AND；例如
`channel ∈ {app, web}` 且 `city = 上海`。符合条件的组合按桶合并 count，只生成一条线。
提供清空标签按钮和所选条件展示。筛选列表可搜索并独立滚动，避免长列表挤压图表。
总览进入详情及返回均保留时间范围，标签条件可保存在详情 URL 中以支持刷新和直接打开。

### 数据语义

- 全量 count 包含所有真实标签组合和 other，桶内计数只计一次。
- 具体标签筛选不能从 other 还原身份；某小时匹配的数据已合入 other 且无法准确统计时，
  该桶为 `null / MERGED_OTHER`，不能用可见子集冒充完整 count，也不能补零。
- 确认没有匹配数据且数据完整时可显示 `0 / ZERO`；未采集、丢弃和未来桶仍为缺口。
- 高对比实线、不连接 null 缺口，沿用已有图表质量提示。
- 不在前端累加现有不完整的 Top1000 标签列表以伪造全量曲线。

## 前端与 mock 边界

新增独立 Metric API 适配模块，负责指标目录、单指标标签候选和 count 趋势请求。
mock 提供多个指标及各自不同的标签数据，并用同一份桶级 count 数据计算全量与筛选曲线，
确保清空条件确实恢复全量、筛选确实改变 count、不同指标不串数据。

现有真实 `/reports/metric/list` 只有标签排名信息，无法满足指标目录及按标签条件精确聚合。
本轮新增能力明确为前端与 mock 契约，不宣称真实后端已支持；不对缺失接口静默回退到
硬编码 `order.amount` 或随机趋势。

总览与详情处理加载、接口错误和空目录/空曲线状态。时间、服务、指标及标签快速切换时，
用请求版本及参数快照阻止旧响应覆盖新状态。

## 时间状态

默认仍为当前整点小时。Metric 页面使用显式传入的时间选择初始化控件，不能让 URL 中的历史范围
与控件默认当前小时出现不一致。必要的 TimeScope 扩展仅增加可选初始选择，不改变其他报表默认行为。
未来窗口不可翻页；跨自然边界后恢复导航可用，不额外引入自动轮询。

## Problem 布局

删除顶部三个说明段落，保留五类矩阵、异常/慢类分位差异、原有 Samples 时间分段和状态配色、
Name 趋势入口及 Trace 下钻。
Problem 与 Metric 使用页面专属全宽样式，解除 `1280px` 上限，不影响其他页面。
行与单元格适度增加留白，Name 和 Samples 分享剩余宽度；窄屏保留横向滚动。
不拉高空行凑满高度，不移除左侧导航。

## 验证与验收

- 真实 SFC 单测：按名称生成小图、默认全量且不预选标签、详情下钻与时间保留、筛选/清空、
  不同键 AND/同键 OR、请求竞态、空态和错误态。
- mock 单测：全量包含 other 且只计一次、筛选聚合来自同一数据源、MERGED_OTHER 保持 null、
  未发生的桶不造数据、不同指标标签不串用。
- 布局回归：Problem 无三段说明，Metric/Problem 取消宽度上限，其余页面样式不变。
- 运行前端 `npm test`、`npm run flow`、`npm run build`（含类型检查），不跑后端测试。
- 用户进行浏览器功能与视觉验收。
