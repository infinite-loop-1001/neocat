# 前端时间导航边界与 Name mock

## 已确认行为

- 快捷范围的 ▶ 仍能进入包含现在的自然小时、周、月。
- 历史窗口可以向前翻到当前窗口；不允许进入起点晚于现在的窗口。
- 当前窗口的 ▶ 禁用；事件处理再次检查边界，不发出未来窗口请求。
- 时钟跨过自然周期边界后，▶ 自动恢复可用。
- 在共享 TimeScope 内处理，应用到所有引用它的报表页面。

## Name mock

- Transaction、Event Name 接口按 range 生成稳定的演示聚合数据。
- 同一窗口重复请求结果一致，历史窗口和不同长度窗口有所区别。
- 未来时段不产生调用数据，QPS = Total / 查询窗口秒数。
- Event 不含耗时、分位字段；未知 Type 返回空列表。
- 数据仅是确定性的演示数据，不宣称与真实趋势严格一致。
