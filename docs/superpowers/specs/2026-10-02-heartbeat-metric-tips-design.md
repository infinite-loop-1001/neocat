# Heartbeat 逐图指标口径悬浮提示

## 已确认设计

- 不再在“内存信息”标题下展示整段口径说明；每张图使用“指标名称 [?] 单位”。
- `?` 只展示当前指标口径，沿用 Heartbeat 编目的 `note`，元空间包含非堆与未设上限说明。
- 鼠标悬停、键盘聚焦显示浮层，触屏点击可开关；Esc、点击外部收起。
- 浮层不参与布局，不撑高图表或挤动机器图例。宽度限制在当前图标题宽度内，文字换行。
- 按钮有指标口径的可访问名称，通过 `aria-describedby` 关联 `role="tooltip"`。
- 不修改指标数据、单位、每实例曲线、机器图例、筛选器或其他报表交互。

## 实现与验证

在 `MiniChart.vue` 将已有内联口径面板替换为标题内的绝对定位浮层，支持悬停、焦点和
点击状态以及关闭后的抑制，避免 Esc 后因焦点仍在按钮上立即重新打开。
样式限定为小图口径入口和浮层；无 `note` 的小图不显示入口。

补真实 SFC 回归测试：标题顺序、浮层定位、默认收起、悬停/焦点、触屏点击、Esc、外部
pointerdown、换指标重置及卸载清理。运行前端单测、动线检查和构建，浏览器验收由用户完成。
