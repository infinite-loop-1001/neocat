# 机器列表与 Hits 配色修正

日期：2026-10-03
状态：已实施，回归及浏览器检查通过。

## 已批准的范围

- 趋势页机器接口只返回实例名，不提供统计数值。删除前端生成的 `40 + index * 13`，列表仅显示复选框和实例名；不新增统计接口或改筛选口径。
- 搜索框可伸缩，选中数量与按钮不拆字；窄屏允许完整控件换行，列表不因最小列宽超出容器。
- 当前 `HITS` 使用黑色 `#000000`，其他统计项当前曲线保持蓝色 `#2563eb`。日/周/月环比继续使用深橙/绿/紫，全部保持实线，图例随序列配色。
- 保留 MachinePicker 的可选数值能力，避免更改其他调用方的契约；只删除趋势页伪造的数据。

## 验证边界

增加真实 SFC 回归：返回实例列表不带伪造数值，选中实例仍传入查询，清空恢复全机器聚合。锁定 HITS 黑色、其他统计项蓝色及环比配色稳定性。执行全量前端测试、类型检查、构建及动线检查；浏览器核对实际图表和机器列表、窄屏布局。

仅做本地前端验证，不作为后端在线采集验收。目录不是 Git 仓库，不能提交或推送。

- 生产改动仅涉及趋势页实例映射、环比函数的当前 HITS 色值、机器搜索框可访问名称与布局。共享组件可选数值接口、实例筛选逻辑和协议均未变；Heartbeat 及 Metric 回归通过。
